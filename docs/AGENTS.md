# docs/AGENTS.md

Documentation hierarchy for Bunnies. Read the root `/AGENTS.md` first.

- `design-system/` — visual, motion, audio, character, navigation rules
- `gameplay/` — gameplay patterns, rewards, progression, difficulty
- `worlds/` — per-world identity and content rules
- `architecture/adr/` — Architecture Decision Records (major decisions)
- `knowledge/CHANGELOG.md` — meaningful architectural/design changes only

Rules:
- Docs capture **reusable knowledge**, not narration of code.
- Update docs when you introduce a reusable pattern or change a convention.
- Do not create docs for one-off implementation details.
