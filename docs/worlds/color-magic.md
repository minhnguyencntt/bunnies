# Phép Màu Sắc (Color Magic) 🌈

- **Game**: Color by Pattern (`color_magic` / `ColorMagicScreen`)
- **Educational goal**: observe a colored reference, remember each part’s
  color, and fill line-art regions until the picture matches
- **Pattern**: GameShell + data-driven `ColorMagicPuzzle` (artwork templates +
  valid color patterns). New artwork = new `ARTWORKS` entry, no gameplay edits
- **Identity**: rainbow magic meadow — peach/lilac sky, crystal flowers,
  glowing mosaic path, color orbs; original storybook bg (not Candy Garden)
- **Loop**: OBSERVE → IDENTIFY → REMEMBER → MATCH → COMPLETE
- **Levels**:
  - Màn 1 · 2–3 vùng, 2–3 màu, hình mẫu luôn lớn, không timer
  - Màn 2 · 4–6 vùng, 3–5 màu, hình mẫu nhỏ hơn, timer nhẹ
  - Màn 3 · 7–10 vùng, 5–7 màu, hình mẫu hiện rồi thu nhỏ (peek), timer
- **Stickers**: 🐰 Thỏ Cầu Vồng · 🌸 Hoa Sắc Màu · 🦋 Bướm Tím · 🎨 Bảng Màu ·
  ⭐ Sao Cầu Vồng · 👑 Vương Miện Màu
- **Awards**: 🎨 Nét Màu Đầu Tiên · 🌈 Chuỗi Sắc Màu (5 streak) ·
  🪄 Bậc Thầy Pha Màu (3⭐ Màn 3)
- **Unlocks**: always available (Discover → Tap → Play)
